# Diagram Modeling

Modification notice: Rewritten and consolidated by Pablo Poo. Attribution and applicable terms: [NOTICE](../../NOTICE.md).

## Inputs

- question to answer
- audience
- entities and relationships

Use available evidence; identify missing information only when it changes the decision.

## Method

- State the question and reader first.
- Include only necessary entities, boundaries, and directed relationships.
- Make ownership, state change, or dependency direction explicit.
- Test labels, grouping, and edge cases against source facts.
- Retain an editable source representation.

## Result

A minimal diagram answering one declared question.

## Scope

Clarifies a model; does not establish missing facts.

Apply within the authorized local development scope. Choose means from the project's existing conventions. Scale evidence to the consequence of error and disclose material limitations.
