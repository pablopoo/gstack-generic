# Documentation Maintenance

Modification notice: Rewritten and consolidated by Pablo Poo. Attribution and applicable terms: [NOTICE](../../NOTICE.md).

## Inputs

- current behavior
- reader intent
- existing documentation and gaps

Use available evidence; identify missing information only when it changes the decision.

## Method

- Identify the reader decision or repeatable task and discover affected documentation by responsibility, including nested sources and authored templates.
- Verify behavioral claims against current evidence.
- Separate confirmed procedure, conditional guidance, and uncertainty.
- Keep the smallest usable structure. Identify the authoritative editable source; generated output alone does not establish ownership.
- Recheck claims after related behavior changes.

## Result

Current documentation or a repeatable procedure with boundaries.

## Scope

Does not invent behavior or replace product decisions. An audit-only request ends with findings and does not authorize documentation edits.

Apply within the authorized local development scope. Choose means from the project's existing conventions. Scale evidence to the consequence of error and disclose material limitations.
