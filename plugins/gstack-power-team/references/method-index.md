# Method Index

Modification notice: Rewritten and consolidated by Pablo Poo. Attribution and applicable terms: [NOTICE](../NOTICE.md).

Select by the decision or result needed. These names identify methods, not executable commands.

| Method | Use when |
| --- | --- |
| [Architecture Planning](../skills/gstack-architecture-planning/SKILL.md) | Resolve responsibilities, boundaries, sequencing, and failure behavior for a consequential change. |
| [Change Review](../skills/gstack-change-review/SKILL.md) | Review current or aging local changes for defects, semantic drift, missing proof, and avoidable complexity. |
| [Comparative Evaluation](../skills/gstack-comparative-evaluation/SKILL.md) | Plan or assess a comparison when alternatives or before-and-after behavior need equivalent evidence. |
| [Content Sampling](../skills/gstack-content-sampling/SKILL.md) | Assess repeated content through a representative declared sample. |
| [Context Stewardship](../skills/gstack-context-stewardship/SKILL.md) | Preserve, restore, and refresh decision-relevant context without trusting stale notes as fact. |
| [Defect Correction](../skills/gstack-defect-correction/SKILL.md) | Reproduce, correct, and verify a defect within bounded implementation scope. |
| [Design Critique](../skills/gstack-design-critique/SKILL.md) | Evaluate an implemented experience for hierarchy, flow, feedback, consistency, and accessibility. |
| [Design Direction](../skills/gstack-design-direction/SKILL.md) | Choose a coherent experience direction when design intent is unsettled. |
| [Design Implementation Planning](../skills/gstack-design-implementation-planning/SKILL.md) | Translate approved design direction into buildable interface decisions. |
| [Diagram Modeling](../skills/gstack-diagram-modeling/SKILL.md) | Make architecture, state, ownership, or dependency relationships legible when prose is insufficient. |
| [Documentation Maintenance](../skills/gstack-documentation-maintenance/SKILL.md) | Create, correct, or formalize documentation from current behavior and decisions. |
| [Early Signal Observation](../skills/gstack-early-signal-observation/SKILL.md) | Observe critical changed behavior for early failure signals. |
| [Evidence Extraction](../skills/gstack-evidence-extraction/SKILL.md) | Extract decision-relevant facts from an artifact or observed surface. |
| [Health Assessment](../skills/gstack-health-assessment/SKILL.md) | Assess correctness, test quality, maintainability, and known risk with explicit coverage. |
| [Implementation Assessment](../skills/gstack-implementation-assessment/SKILL.md) | Assess implementation choices or code-reuse opportunities against requirements and maintenance costs. |
| [Integrated Plan Review](../skills/gstack-integrated-planning/SKILL.md) | Turn a proposed plan into an ordered, testable delivery plan. |
| [Integration Handoff](../skills/gstack-integration-handoff/SKILL.md) | Establish whether completed local work is ready to transfer, integrate, or continue. |
| [Method Codification](../skills/gstack-method-codification/SKILL.md) | Create or revise reusable guidance when repeated verified work exposes a missing decision rule or stale overlap. |
| [Product Challenge](../skills/gstack-product-challenge/SKILL.md) | Challenge the value and scope of a proposed product direction before committing effort. |
| [Product Discovery](../skills/gstack-product-discovery/SKILL.md) | Test whether an idea addresses a specific urgent problem before committing scope. |
| [Readiness Triage](../skills/gstack-readiness-triage/SKILL.md) | Order pending work by dependency, conflict, and evidence needed to become ready. |
| [Retrospection](../skills/gstack-retrospection/SKILL.md) | Extract durable lessons from a completed work cycle using verified outcomes. |
| [Risk Assessment](../skills/gstack-risk-assessment/SKILL.md) | Assess security, safety, privacy, or misuse risk for a defined surface. |
| [Root Cause Investigation](../skills/gstack-root-cause-investigation/SKILL.md) | Establish the cause of unexpected behavior before choosing a repair. |
| [Scenario Evaluation](../skills/gstack-scenario-evaluation/SKILL.md) | Evaluate an interaction or functional contract across representative states without changing the product. |
| [Scope Control](../skills/gstack-scope-control/SKILL.md) | Set or revise a safe boundary for broad, destructive, or expanding work. |
| [Specification](../skills/gstack-specification/SKILL.md) | Turn ambiguous intent into bounded scope, decisions, and testable acceptance criteria. |
