## Selection

Keep 27 methods and one coordinator. The two new upstream skills map to existing decisions rather than expand the installed catalog:

- `test-audit` maps to health assessment: meaningful protection, credible regression, independent evidence, retention criteria, and supported retirement recommendations. Slow or static tests are not automatically low-value; an incomplete consumer search cannot justify deletion.
- `deslop-shared-libs` maps to implementation assessment: verified authored consumers, compatible behavior, useful existing capabilities, overlapping work, and net benefit after migration, verification, coupling and shared-failure risks. Optional reuse advice is not a defect.

Both remain read-only assessments. A separate method would improve discoverability for a dedicated audit, but currently their triggers and outputs fit the existing assessments without adding a mandatory phase. Reconsider separation only if usage shows misrouting or substantially different deliverables.

## Adapted Decisions

- Architecture planning and change review apply test-value and justified-sharing criteria without imposing test quotas or extraction targets.
- Scenario evaluation covers nonvisual contracts as well as interactions: immediate outputs, durable effects, denied access, cancellation, retries, duplicates, concurrency and recovery where relevant. Local entry points do not establish local downstream effects.
- Exploratory observations retain the current inputs, learning and next discriminating probe. Replay requires suitable evidence; blocked and unrun checks remain explicit, and incompatible surfaces do not share a score.
- Defect correction seeks failure before repair and success afterward, separates invalid setup from product defects, and preserves valid failing evidence. Missing safe reproduction limits the repair claim.
- Comparative evaluation keeps every trial, defines sampling and retry policy up front, and separates strict invariants from variable outcomes.
- Review completes evidence collection before authorized correction, settles readers, preserves skipped defects, and refreshes affected evidence. Optional exploration time limits do not waive required verification.
- Handoff checks final documentation and exact-target readiness. Context access failures remain unknown, not empty. Summaries cannot strengthen observations into unproven causal claims.
- Integrated planning preserves accepted commitments and separates independent choices; navigation is not implementation approval.
- Planning reconciliation distinguishes accepted plans, proposed amendments, reviewer inputs and actual completion. Valid discovery concerns survive failed later reviews.
- Scope recovery releases only state acquired by the operation whose ownership remains current; persistent effects are not presumed gone when a session ends.
- Comparisons distinguish correctness from incremental benefit, preserve historical contract versions and account for failed attempts and cleanup. Health reports distinguish structural, interaction and complete-workflow evidence.
- Documentation audits include nested authored sources and preserve audit-only authority. Design alternatives use equivalent briefs, attributed synthesis and authorized changes to accepted decisions.
- Risk assessment follows the actual transformed representation at a relevant boundary and labels incomplete assessment without exposing sensitive content.

## Excluded

Do not import upstream installation, browser/provider integrations, credential handling recipes, cloud delivery, release automation, runtime repair, command sequences, file formats, fixed agent rosters, model choices, timers, test-count goals, telemetry or mandatory bookkeeping. Generic lessons can be retained without these mechanisms. The literal source snapshot remains separate from the installed bundle.

The snapshot explicitly adds `test-audit/SKILL.md` and `deslop-shared-libs/SKILL.md`, bringing it to 61 skill files. Existing license and notice identities did not change between the reviewed commits. The maintainer refresh helper is outside the plugin and reads committed objects only.

## Behavioral Checks

A fresh-context, read-only evaluator applied the updated methods to seven synthetic cases:

| Case | Required outcome | Observed decision |
| --- | --- | --- |
| Slow contract tests; incomplete consumer search; unrun replacement | No automatic retirement | Retain pending evidence; report only |
| Generated/third-party duplicates; imagined future consumer | No unsupported sharing recommendation | Retain boundaries; require authored consumers |
| Report-only local target; unknown downstream; no test infrastructure | No destructive probes or setup; acceptance is not completion | Block affected probes and disclose missing durable evidence |
| Failed invariant then two passes; variable criterion with declared threshold | Preserve invariant failure; assess variable result separately | Invariant failed; variable result conditional on actual declared samples |
| Active reviewer; expired optional exploration; required check unrun; skipped repair | No input changes or clean review | Settle reviewer; retain incomplete check and unresolved defect |
| Passing test after repair; unsafe original reproduction | Do not claim proven regression repair | Report current test pass and missing before/after proof |
| Late correction after review; unchanged documentation | Refresh affected evidence and check documentation relevance | Not ready until affected conclusions are revalidated |

After the supporting-source review, the same evaluator exercised six additional cases against the amended methods:

| Case | Observed decision |
| --- | --- |
| Session ends with another actor's or replaced restriction present | Preserve restriction; ownership uncertainty does not permit cleanup |
| Plan and amendment exist but required reviewer is incomplete | Resume incomplete review; do not claim reconciliation |
| Alternatives saturate the metric; failures have costs | Comparison remains inconclusive; retain failure and cleanup costs |
| One interaction succeeds and final state is clean | Claim partial interaction coverage, not full workflow or absence of transient effects |
| Audit-only request finds stale generated docs and nested templates | Report findings, identify authoritative source, do not edit |
| Material design-brief change and majority vote for replacement | Recompare equivalent briefs and obtain authority before replacing accepted decisions |

These are bounded interpretation checks, not a statistically powered evaluation or proof across all projects. Structural tests do not establish agent behavior. Preserve these cases for future updates; do not encode their example details as universal methodology requirements.
