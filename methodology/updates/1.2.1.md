# Methodology Update 1.2.1

This packaging-only patch omits the optional author email field from the plugin manifest. The author name, license attribution, 27 methods, coordinator and pinned upstream snapshot remain unchanged.

The package guard now permits only the author's name in author metadata. A negative fixture verifies that adding a contact email fails validation. The methodology generator does not generate author metadata and requires no change.

Validation covers all 36 maintenance tests, reproducible methodology generation and unchanged license files. These structural checks do not guarantee agent behavior across every host or project.
